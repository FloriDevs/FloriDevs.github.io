🚀 Einführung

MillaScript ist eine einfache, aber leistungsfähige Programmiersprache, die speziell für Milla OS entwickelt wurde. Sie ist ideal für Anfänger und ermöglicht es, schnell interaktive Programme zu erstellen.

Hauptmerkmale

  • ✅ Einfache, verständliche Syntax
  • ✅ 26 Variablen (A-Z)
  • ✅ Arithmetische Operationen
  • ✅ Bedingte Sprünge und Schleifen
  • ✅ Interaktive Benutzereingabe
  • ✅ Integrierter Code-Editor mit Syntax-Highlighting

🎯 Quick Start

1. Code-Editor öffnen

Im Hauptmenü von Milla OS: 3. Code Editor auswählen

2. Dein erstes Programm

Hello World

PRINT "Hello, World!"
PRINT "Willkommen zu MillaScript!"

3. Programm speichern und ausführen

  • F1 - Speichern
  • F2 - Ausführen
  • F3 - Hilfe anzeigen
  • ESC - Editor verlassen
💡 Tipp: Alle MillaScript-Programme sollten die Endung .MSC haben!

📋 Befehlsreferenz

PRINT
Syntax: PRINT "Text" oder PRINT Variable
Gibt Text oder den Wert einer Variable auf dem Bildschirm aus.

Beispiele

PRINT "Hallo!"
SET A 42
PRINT A
SET
Syntax: SET Variable Wert
Weist einer Variable einen Wert zu.

Beispiele

SET A 10
SET B -5
SET C A
ADD
Syntax: ADD Variable Wert
Addiert einen Wert zu einer Variable.

Beispiele

SET A 5
ADD A 3  // A ist jetzt 8
ADD A B  // Addiert Wert von B
SUB
Syntax: SUB Variable Wert
Subtrahiert einen Wert von einer Variable.

Beispiele

SET A 10
SUB A 3  // A ist jetzt 7
INPUT
Syntax: INPUT Variable
Fordert den Benutzer zur Eingabe einer Zahl auf und speichert sie in der Variable.

Beispiel

PRINT "Gib eine Zahl ein:"
INPUT A
PRINT "Du hast eingegeben:"
PRINT A
DELAY
Syntax: DELAY Zyklen
Pausiert die Programmausführung für die angegebene Anzahl an Zyklen.

Beispiel

PRINT "Warte..."
DELAY 100
PRINT "Fertig!"
CLS
Syntax: CLS
Löscht den Bildschirm.
GOTO
Syntax: GOTO Label
Springt zur angegebenen Label-Position im Programm.

Beispiel

GOTO ende
PRINT "Dies wird übersprungen"
ende:
PRINT "Programmende"
IF
Syntax: IF Wert1 Operator Wert2 GOTO Label
Springt zum Label, wenn die Bedingung erfüllt ist.

Verfügbare Operatoren

Operator Bedeutung Beispiel
== Gleich IF A == 5 GOTO label
!= Ungleich IF A != 0 GOTO label
> Größer als IF A > 10 GOTO label
< Kleiner als IF A < 5 GOTO label
>= Größer oder gleich IF A >= 10 GOTO label
<= Kleiner oder gleich IF A <= 5 GOTO label

📊 Variablen

MillaScript bietet 26 globale Variablen, benannt von A bis Z.

Eigenschaften

  • Alle Variablen speichern Integer-Werte (ganze Zahlen)
  • Startwert aller Variablen ist 0
  • Unterstützt negative Zahlen
  • Keine Deklaration nötig

Variablen verwenden

SET A 10
SET B 20
SET C A
ADD C B
PRINT C  // Gibt 30 aus
⚠️ Hinweis: Variablen sind case-sensitive! A und a sind unterschiedliche Variablen (aber nur Großbuchstaben werden unterstützt).

🔄 Kontrollstrukturen

Labels

Labels markieren Positionen im Code, zu denen gesprungen werden kann.

start:
PRINT "Schleife"
GOTO start

Schleifen

Schleifen werden mit Labels und bedingten Sprüngen erstellt.

Zählschleife (For-Loop)

SET I 0
loop:
PRINT I
ADD I 1
IF I < 10 GOTO loop
PRINT "Schleife beendet"

While-Loop

SET A 100
while:
IF A <= 0 GOTO ende
PRINT A
SUB A 10
GOTO while
ende:
PRINT "Fertig!"

Bedingte Ausführung

If-Then-Else simulieren

INPUT A
IF A > 10 GOTO gross
PRINT "Zahl ist klein oder gleich 10"
GOTO ende
gross:
PRINT "Zahl ist groesser als 10"
ende:

💡 Beispielprogramme

1. Zahlenraten-Spiel

SET S 42
SET V 0
start:
PRINT "Rate die Zahl (0-100):"
INPUT G
ADD V 1
IF G == S GOTO gewonnen
IF G > S GOTO zuGross
PRINT "Zu klein!"
GOTO start
zuGross:
PRINT "Zu gross!"
GOTO start
gewonnen:
PRINT "Richtig! Versuche:"
PRINT V

2. Countdown-Timer

PRINT "Countdown von:"
INPUT N
CLS
loop:
IF N < 0 GOTO ende
PRINT N
DELAY 50
SUB N 1
GOTO loop
ende:
PRINT "Start!"

3. Fibonacci-Zahlen

PRINT "Wie viele Fibonacci-Zahlen?"
INPUT N
SET A 0
SET B 1
SET I 0
loop:
IF I >= N GOTO ende
PRINT A
SET C A
ADD C B
SET A B
SET B C
ADD I 1
GOTO loop
ende:
